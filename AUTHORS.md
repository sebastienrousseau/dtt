# Authors

`DateTime (DTT)` is maintained by:

- **[Sebastien Rousseau](https://github.com/sebastienrousseau)** — original author and maintainer

## Contributors

Thanks to everyone who has contributed code, documentation, bug reports,
and feedback. The full list is available on the
[GitHub contributors page](https://github.com/sebastienrousseau/dtt/graphs/contributors).

## How to be listed here

Open a pull request following [`CONTRIBUTING.md`](CONTRIBUTING.md). All
contributions — code, docs, tests, bug reports — are welcome and
appreciated.

All commits must be cryptographically signed (`git commit -S`). See the
[Signed Commits section](CONTRIBUTING.md#2-signed-commits-required) for
one-time setup instructions.
